# Enterprise AI Agent Platform

Infrastructure-agnostic Enterprise AI Agent Platform.

## Features
- Infrastructure-agnostic (Models, Data, Knowledge Systems)
- Natural-language agent creation & visual builder
- Composable agents & workflow engine
- No-code to Pro-code SDK & CLI

## Development
This repository uses `uv` for Python dependency management and monorepo workspace orchestration.

```bash
# Sync dependencies
uv sync

# Run tests
uv run pytest

# Run linter
uv run ruff check .
```
